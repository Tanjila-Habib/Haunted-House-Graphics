# 🏚️ Haunted House at Night

An interactive, animated 2D graphics project that takes you through a spooky haunted house across multiple scenes. Use your mouse and keyboard to interact with the world and trigger surprises.

## 🎬 Scenes

Switch scenes by pressing **1**, **2**, **3** or **4**.

| Scene | Description |
|-------|-------------|
| **1. Outside View** | Stormy night with moving clouds, lightning, flying bats, a swaying tree, a car with blinking headlights, a skeleton and a cracked gravestone. |
| **2. Haunted Room** | Candles, a fireplace, a swinging chandelier, a wall clock, a window with rain and a mirror that cracks to reveal a jumpscare ghost. |
| **3. Haunted Corridor** | Blinking bulbs, crawling spiders and cockroaches, falling rain, a floating ghost and a door that opens and closes. |

## 🎮 Controls

### ⌨️ Keyboard
| Key | Action |
|-----|--------|
| `1` `2` `3` `4` | Change scene |
| `L` | Toggle lightning |
| `H` | Car headlights on/off |
| `B` | Stop/start bats |
| `Z` | Change arrow direction (clockwise/anticlockwise) |
| `W` | Stop the moving arrow |
| `D` | Ring the doorbell |
| `T` | Drive the car out of the scene |
| `R` | Rain on/off (with lightning and a cracked gravestone, or rain sound) |
| `N` | Switch night/day |
| `C` | Freeze/resume candle flames |
| `F` | Fireplace on/off |

### 🖱️ Mouse
| Action | Result |
|--------|--------|
| Left click | Slow down clouds and arrow, remove blood stain |
| Right click | Speed up clouds and arrow, add blood stain |
| Hover | Change bats' direction, make candle flames bigger, change fireplace flame colors |
| Click | Crack the mirror and show the ghost, reverse plate motion, toggle the fireplace |

> ⚠️ **Warning:** There is a jumpscare sound, so lower your volume first!

## 🛠️ Built With
-   C++ with OpenGL/GLUT
